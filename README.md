# 小二數學科練習

專為小二學童設計的 iPad 友善 Progressive Web App（靜態網頁）。可選擇多份試卷練習，全程繁體中文，可離線使用，無需安裝 App、無 CDN。

## 試卷列表

| 試卷 | 主題 | 來源 | 計分 |
|------|------|------|------|
| 數學文字題 | 乘除、加減、半打／一打、分組、購物 | 多份小二試卷應用題 OCR 精選（另補一題「一打」） | ✅ |
| 小測（基本乘法） | 基本乘法 | 2022–23 小測 PDF | ✅ |
| 小測（基本除法） | 基本除法 | 2021–22 小測 PDF | ✅ |
| 小測（四位數） | 四位數 | 下學期小測 PDF | ✅ |
| 小測（三位數及數數） | 三位數／數數 | 2022–23 小測 PDF | ✅ |
| 小測（象形圖） | 象形圖 | 下學期小測 PDF | ✅ |
| 進展性評估（5） | 加減運算 | 2024–25 評估 + 答案 | ✅ |
| 上學期測驗（精選） | 綜合 | 2024–25 測驗 + 答案 | ✅ |

原卷若含大量畫圖／量角器題（例如「角和垂直線」整卷），未作完整互動化，見下方「略過說明」。

## 在 iPad／電腦開啟

**必須用靜態伺服器**（題庫為 JSON，`file://` 無法 fetch）：

```bash
cd p2-quiz
python3 -m http.server 8080
# 瀏覽器或 iPad Safari：http://<電腦區網IP>:8080
```

加入主畫面：Safari → 分享 →「加入主畫面」。

## 使用說明

1. 在開始畫面可直接按「數學文字題」開始，或點選其他試卷（可看到主題／年份／題數）。
2. （可選）輸入姓名，按「開始答題」。
3. 每頁一題；數字鍵盤或大選項卡作答。
4. 交卷後查看分數與正確答案；可「再試一次」或「返回試卷列表」。

進度鍵：`p2-quiz-v2:<試卷id>`（每卷獨立；交卷或再試會清除該卷進度）。

## 略過／未完整數位化

| PDF | 原因 |
|-----|------|
| 角和垂直線小測 | 幾乎全是畫角、垂直線、平行線圖形作答，不適合純數字互動；未列入可玩列表 |
| 各長卷考試全文（第三段考、段考等） | 頁數多、圖多；優先做短小測與有答案卷的評估／測驗精選 |
| 答案-only PDF | 不單獨成卷；已配對用於計分（如 24–25 評估／測驗答案） |
| 象形圖第 2 頁畫圖題 | 需手繪象形圖；只數位化第 1 頁讀圖題 |

## 技術備註

- 純靜態 HTML／CSS／JS；題目由 `data/` JSON 載入。
- 題型：直式、填空、交換律、選擇、應用題、多空排序。
- 專為觸控：大按鈕、螢幕數字鍵盤、safe-area。
